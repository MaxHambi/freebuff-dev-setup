# Issue Tracker: GitHub

Issues für dieses Repo (`MaxHambi/tools-entwicklung`) leben in **GitHub Issues**:
https://github.com/MaxHambi/tools-entwicklung/issues

## Konventionen

- Issues werden mit der `gh` CLI veröffentlicht (`gh issue create`), in Abhängigkeitsreihenfolge (Blocker zuerst), damit "Blocked by"-Verweise echte Issue-Nummern sind.
- PRs sind **kein** Triage-Surface (solo Repo, keine externen PR-Anfragen).
- Engineering-Skills (`to-prd`, `to-issues`, `triage`, `qa`) lesen/schreiben über `gh issue`-Kommandos.
- PRD- bzw. Plan-Issues werden mit `ready-for-agent` gelabelt (siehe `triage-labels.md`).
